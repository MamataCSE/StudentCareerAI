StudentCareerAI 🎓

About the Project

StudentCareerAI is a student career guidance system developed using Python and Streamlit.

Features

- Student Profile
- Career Recommendations
- Skill Gap Analysis
- Learning Roadmap
- Internship Preparation
- Downloadable Career Report

Technologies Used

- Python
- Streamlit

How to Run

1. Install Python.
2. Install the required library:
   "pip install -r requirements.txt"
3. Run the application:
   "python -m streamlit run app.py"
