StudentCareerAI 🎓

About the Project

StudentCareerAI is a student career guidance system developed using Python and Streamlit.

Features

- Student Profile
- Career Recommendations
- Skill Gap Analysis
- Learning Roadmap
- Internship Preparation
- Downloadable Career Report

Technologies Used

- Python
- Streamlit
- SQLite Database

How to Run

1. Install Python.

2. Open the terminal in the project folder.

3. Install the required libraries:
   
   pip install -r requirements.txt

4. Run the application:
   
   python -m streamlit run app.py
